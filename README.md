# 个人学习transformer的理解

   代码是从《从零开始构建智能体》第3.1章上抄下来的

只看transformer右边的解码器，可以依次分为下面几个模块

* 词嵌入矩阵
* 位置编码
* 多头注意力机制
* 残差链接与归一化
* 前馈神经网络
* 线性投影
* softmax归一化

### 1.词嵌入矩阵

* 问题：在自然语言中，一个词包含着多重的含义，机器如何学习与理解。
* 解决方法：利用神经网络的计算能力以及transformer架构，让模型自己学习词语的含义。

  词向量是模型通过大量的语料文本训练出来的，它有着一套只有模型读得懂的向量，这些向量可以一定程度的比较好的表达出词语的含义。

  包含$W_q$,$W_k$,$W_v$,这些也是模型通过学习得出，词嵌入矩阵、以及这三个矩阵合在一起，才是的模型能够读懂词语的含义。

##### 词嵌入矩阵与权重矩阵的训练

	在transformer架构中，词嵌入矩阵的训练，主要靠大量的语料文本输入，结果验算，反向传播修改权重等等来实现。

	(1) 语料文本经过分词输入

	(2)分词后赋予词位置矩阵与词向量(随机值)

	(3)输入后利用掩码机制(只看前n个词)

	(4)输入神经网络，利用权重矩阵计算后输出一个概率最大的下一个词，利用原文文本进行评估

	(5)算出loss利用反向传播算法，进行对权重矩阵和词嵌入矩阵的纠错，以此达到使模型可以正确的理解词

### 2.位置编码

* 问题：注意力机制完全丢失了位置信息。
* 解决方法：加入一个位置编码，让模型知道具体的位置信息。

  位置编码经过了许多种的变化，从最开始的transformer架构里面的固定正弦余弦编码到现在的旋转位置编码RoPE，大体上就是在让这个位置编码加上更多的信息

##### (1)绝对位置编码

	核心逻辑：给序列中每个 绝对位置（第 0 位、第 1 位… 第 n 位）分配一个独有的向量，直接和词向量相加，让模型知道 “这个词在第几个位置”。

* 固定正弦余弦编码（Sinusoidal PE）
* 可学习绝对位置编码（Learned PE）

##### (2)相对位置编码

	因自然语言的语义关系大多由相对距离决定（比如 “我吃饭” 中 “我” 和 “饭” 的主谓宾关系，和它们在第几位无关，只和隔了几个词有关），于是转向直接建模 token 间的相对距离。

* Transformer-XL 相对位置编码
* T5 相对位置偏置（RPE）

##### (3)旋转位置编码 RoPE

	核心逻辑：不给向量 “加东西”，而是把向量 “转一下”—— 对 Q 和 K 向量施加一个和位置相关的旋转矩阵，位置越靠后，旋转角度越大

### 3.多头注意力机制

	注意力机制的核心是对每一个词向量生成三个qkv向量。

* q向量：从token自身的角度看出去。
* k向量：token在外面看起来包含的信息。
* v向量：token本身蕴含的价值。

$$
\text{Attention}(Q,K,V) = \text{softmax}\left( \frac{QK^\top}{\sqrt{d_k}} \right) V

$$

	此公式最核心的意思实际就是从 token_1 的视角查询token_2(QK向量的相乘),这之后这两个token之间就会有联系，根据这个联系，就可以获得这两个token在这种关系下的含义，也就是v向量。

	举个例子，比如小米和苹果，这两个词的联系与含义就有电子产品与农产品这两种，而小米和大米，这两个词的联系就只有农产品。

	而多头指的就是把词向量从开始就分成多个，以此叫多头。

### 4.残差链接与归一化

	用与防止神经网络中的梯度消失以及内部协变量偏移的问题。

### 5.前馈神经网络

	通过引入非线性层，对每一个token进行处理，其中的权重矩阵通过反向传播算法拟合。

### 6.线性投影，softmax归一化

	融合多头，可以通过归一化控制输出的严肃还是自由。
